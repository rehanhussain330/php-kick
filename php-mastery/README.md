## How to Use This Guide

Each folder contains multiple example files with:
- Detailed comments explaining the code
- Expected output
- Real-world use cases
- Best practices

## Prerequisites

- PHP 8.0 or higher
- Composer (for package management)
- Node.js & npm (for React and Tailwind)
- Database servers (MySQL, PostgreSQL, MongoDB)

## Getting Started

```bash
# Navigate to any topic folder
cd 01-basics

# Run PHP files
php filename.php
```
